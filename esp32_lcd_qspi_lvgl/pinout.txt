
1. 项目简介

本项目基于 **ESP32-S3** 开发板，驱动 **TK018F3716 1.18 寸 QSPI LCD（368×448）**，运行 **LVGL** 图形界面，实现一个智能手表风格的四页面应用：

| 页面 | 名称 | 功能 |
|------|------|------|
| 0 | MEASURE（测量） | 风速实时测量（当前/平均/最大值）、温湿度气压显示 |
| 1 | RECORD（记录） | 心率带状图、历史数据图表（含渐变阴影折线图） |
| 2 | SETUP（设置） | 屏幕亮度调节滑条、恢复出厂设置按钮 |
| 3 | MORE（更多） | 设备信息查看 |

 2. 硬件连接

| 信号 | GPIO | 说明 |
|------|------|------|
| LCD CS 			| 16 				| QSPI 片选 |
| LCD PCLK 		| 6 				| 像素时钟 |
| LCD DATA0~3 	| 15 / 7 / 17 / 18 	| QSPI 数据线 |
| LCD RST 			| NC 				| 复位引脚未使用 |
| 背光 			| NC 				| 背光由 DCS 命令 0x51 控制 |
| 触摸 I2C SCL 		| 5 				| 触摸芯片时钟线 |
| 触摸 I2C SDA 		| 4 				| 触摸芯片数据线 |

- 触摸芯片支持 **CHSC6417**，通过 `main.c` 中 `TOUCH_CHIP` 宏切换（`1` = CHSC6417，`0` = FT5x06）。
- 触摸开关：`TOUCH_ENABLE`（`1` 启用，`0` 关闭）。

3. 编译与烧录

idf.py set-target esp32s3

选择idf-5.5.2


 4. 界面操作

 4.1 页面切换
底部导航栏：点击 MEASURE / RECORD / SETUP / MORE 四个按钮直接跳转。
手势滑动：在页面空白区域左右滑动可切换页面。

4.2 测量页（MEASURE）
实时显示当前风速、平均值（AVG）、最大值（MAX）。
环境栏显示温度、湿度、气压（当前为模拟数据，接传感器后替换 `env_timer_cb`）。
HOLD 按钮：暂停/保持当前测量数值，旁边依次显示 WiFi、蓝牙、电池状态图标。

 4.3 记录页（RECORD）
心率卡片带呼吸动效，数值周期性更新。
历史曲线图采用"三角形 + 矩形 + 垂直渐变"绘制阴影，避免黑边缝隙。

4.4 设置页（SETUP）
亮度滑条：拖动调节屏幕亮度，范围 **5% ~ 100%**（下限 5% 防止误操作导致黑屏）。
亮度通过 DCS 命令 `0xFE=0x00`（选 Page 0）→ `0x51=值`（0~255）写入，与驱动初始化序列一致。
串口会打印 `LCD brightness set to X% (0xXX)` 便于验证。
RESET SETTINGS 按钮：恢复默认设置（亮度回到 80%）。

 4.5 更多页（MORE）
显示设备固件版本、分辨率、像素格式等信息。

5. 亮度控制原理（TK018F3716 专有）

该屏的控制器对 DCS 命令处理**非标准**，必须遵循厂商初始化序列：

- 直接发送 `0x53`（显示控制）+ `0x51` 的标准写法**无效**，必须先切页。
- 亮度百分比换算：`val = percent × 255 / 100`。
- 相关代码位置：[main.c](../main/main.c) 的 `lcd_set_brightness()`。

6. 常见问题（FAQ）

Q1：调亮度滑条屏幕亮度不变？
检查串口是否有 `LCD brightness set to X%` 日志。若无，确认 `lcd_set_brightness()` 中命令序列为 `0xFE=0x00` → `0x51=val`（历史版本曾用 `0x53=0x24`，已废弃）。

Q2：切换 RGB888 后花屏/颜色异常？
确认已删除 `esp_lcd_tk018.c` 中硬编码的 `{0x3A, 0x55}` 命令，且 `sdkconfig` 中 `LV_COLOR_DEPTH=24` 已生效（需全量重新编译）。

Q3：触摸无反应？
确认 `TOUCH_ENABLE = 1`。
确认 `TOUCH_CHIP` 与实际焊接的触摸芯片一致。
CHSC6417 使用两段式 I2C 协议（写 0x5C / 读 0x5D），地址配置错误会返回 NACK。
